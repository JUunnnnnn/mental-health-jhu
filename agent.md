# Agent instructions

Follow the full repository guidance in [agents.md](agents.md).

- Never commit or push directly to `main` or `master`.
- Make every change on a feature or fix branch.
- Merge into the default branch only through a reviewed pull request.
- Preserve collaborators' work and existing coursework.
- Use `uv` for all Python development, dependencies, scripts, and tools.
- Run `npm start` for the web app at http://localhost:3000 and `npm test` for its checks.
- Keep safety responses separate from the custom, non-diagnostic wellness index.
